# Teacher Nicole v5.9.5

Fixes the calendar edge indicators structurally: indicator overlays now sit outside the scrolling 24-hour grid as siblings pinned to the visible calendar viewport. Earlier/later counts still derive from the grid scroll position and visible height, but the controls themselves cannot scroll away. This preserves full-day scrolling, the noon default position, Outlook-style alignment, lesson details and V5.8 Outlook sync.
